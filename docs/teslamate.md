# TeslaMate 설명

최종 업데이트: 2026-06-10

## 한 줄 설명

TeslaMate는 테슬라 차량 데이터를 내 서버에 계속 저장해두는 오픈소스 데이터 로거다.

공식 Tesla 앱이 “차량 제어 앱”이라면, TeslaMate는 “내 차의 장기 기록 창고”에 가깝다.

## TeslaMate가 하는 일

TeslaMate는 차량에서 얻을 수 있는 주행, 충전, 상태 데이터를 기록하고 Grafana 대시보드로 보여준다.

대표적으로 볼 수 있는 항목:

- 주행 기록
- 충전 기록
- 충전 비용
- 배터리 잔량 변화
- 예상 주행 가능 거리 변화
- 효율
- 소프트웨어 업데이트 기록
- 차량이 깨어 있던 시간과 잠든 시간
- 뱀파이어 드레인
- 방문 위치
- 집, 회사, 자주 가는 장소 같은 지오펜스

## 구성 요소

TeslaMate는 보통 Docker Compose로 여러 서비스를 같이 띄운다.

### TeslaMate

데이터를 수집하고 기본 웹 화면을 제공하는 본체다.

### PostgreSQL

수집한 차량 데이터를 저장하는 데이터베이스다.

주행, 충전, 위치, 상태 변화 같은 기록이 여기에 쌓인다.

### Grafana

저장된 데이터를 차트와 대시보드로 보여주는 도구다.

TeslaMate의 강점은 이 Grafana 대시보드가 꽤 풍부하다는 점이다.

### Mosquitto

MQTT 브로커다.

차량 상태를 다른 홈 자동화 도구나 개인 시스템에 전달할 때 사용한다. 처음에는 몰라도 된다.

## 공식 Tesla 앱과 다른 점

공식 Tesla 앱:

- 문 열기
- 공조 켜기
- 충전 시작/중지
- 위치 확인
- 차량 제어
- 공식 지원

TeslaMate:

- 장기 데이터 저장
- 주행/충전 통계
- 배터리/효율 추세
- 내 데이터 직접 소유
- Grafana 분석
- 직접 운영 필요

즉, TeslaMate는 공식 앱의 대체재가 아니다.

## 왜 쓰는가

### 장기 기록

테슬라 앱은 일상 제어에는 좋지만, 내 차의 장기 기록을 자세히 보관하고 분석하는 용도는 제한적이다.

TeslaMate는 “지난달 충전비가 얼마였지?”, “겨울에 효율이 얼마나 떨어졌지?”, “집밥 충전 비중이 얼마나 되지?” 같은 질문에 답하기 좋다.

### 내 데이터 소유

상용 앱에 데이터를 맡기지 않고 내 서버에 저장할 수 있다.

다만 이 장점은 서버와 보안을 직접 관리할 때만 의미가 있다.

### Grafana 대시보드

이미 만들어진 대시보드가 많다.

처음부터 차트를 직접 만들지 않아도 주행, 충전, 배터리, 위치 데이터를 꽤 깊게 볼 수 있다.

## 단점과 위험

### 운영 난이도

그냥 Vercel에 올리는 웹앱과 다르다.

항상 켜져 있는 서버가 필요하고 Docker, DB 백업, 업데이트, 보안 설정을 관리해야 한다.

### 보안

TeslaMate는 테슬라 계정 토큰과 차량 데이터를 다룬다.

인터넷에 그대로 노출하면 위험하다. 공식 문서도 홈 네트워크, VPN, Tailscale, Cloudflare Tunnel, 리버스 프록시 같은 안전한 접근 방식을 권장한다.

### 차량 수면 문제

잘못 설정하거나 다른 데이터 로거와 같이 쓰면 차량이 자주 깨어 있을 수 있다.

차량이 잠을 잘 못 자면 대기 전력 소모가 늘 수 있다.

### API 변화

테슬라 API 정책은 계속 바뀐다.

공식 Fleet API는 과금, 제한, 가상 키, 텔레메트리 설정 같은 요소가 있고, 개인이 직접 다루기에는 생각보다 무겁다.

### 모바일 사용성

Grafana는 강력하지만 모바일에서 매일 보기 좋은 앱은 아니다.

그래서 나중에 우리 앱이 TeslaMate 위에 “오너용 요약 화면”을 얹는 방향이 더 좋을 수 있다.

## 설치에 필요한 것

기본적으로 다음이 필요하다.

- 인수 완료된 테슬라 차량
- 테슬라 계정 접근
- Docker를 돌릴 수 있는 항상 켜진 머신
- 최소 1GB 이상 메모리, 권장 2GB 이상
- 안전한 접속 방식
- 정기 백업

가능한 운영 장소:

- 집 NAS
- 미니 PC
- 라즈베리 파이급 장비
- 개인 VPS
- Railway 같은 클라우드 서비스
- TeslaMate 호스팅 서비스

개인적으로는 집 안에 항상 켜둘 장비가 있다면 홈서버 + Tailscale이 가장 자연스럽다. 없다면 처음부터 무리하지 않는 편이 낫다.

## 우리 프로젝트와 연결하는 방법

이 레포의 앱 안에 TeslaMate를 직접 넣지는 않는다.

권장 구조:

1. TeslaMate는 별도 서버에서 운영한다.
2. TeslaMate의 PostgreSQL DB에 데이터가 쌓인다.
3. 우리 앱은 필요한 요약 데이터만 읽는다.
4. 사용자는 Grafana 대신 우리 앱에서 쉬운 요약을 본다.

우리 앱에서 보여줄 만한 요약:

- 이번 달 충전 비용
- 집밥/슈퍼차저/외부 충전 비중
- 최근 주행 효율
- 배터리 잔량 패턴
- 주차 중 대기 전력 소모
- 소프트웨어 업데이트 기록
- 자주 가는 장소
- 월별 주행거리

## 지금 당장 필요한가

아니다.

차가 아직 없기 때문에 지금 TeslaMate를 붙여도 실제로 쌓을 데이터가 없다. 지금은 다음 작업이 더 중요하다.

- 인수 준비 체크리스트
- 커뮤니티 정보 정리
- 액세서리 결정
- 충전 환경 준비
- 보험과 보조금 정보 정리

## 언제 도입하면 좋은가

차를 받은 뒤 2주에서 1개월 정도 공식 앱만 써본다.

그 후 다음 질문에 “그렇다”가 많으면 TeslaMate를 도입할 가치가 있다.

- 내 충전비를 자동으로 기록하고 싶은가?
- 장기 배터리 추세를 보고 싶은가?
- 집밥과 외부 충전 비중을 알고 싶은가?
- 주행 효율을 계절별로 보고 싶은가?
- 데이터가 상용 앱 서버가 아니라 내 쪽에 남았으면 하는가?
- 서버 운영과 보안 관리가 크게 부담스럽지 않은가?

## 추천 결론

현재 단계에서는 TeslaMate를 바로 붙이지 않는다.

대신 우리 앱을 먼저 만들고, 나중에 다음 방식으로 확장한다.

1. 8월 인수 전: 준비/정보/결정 앱 완성
2. 인수 후 2주: 공식 Tesla 앱만 사용하며 실제 니즈 확인
3. 인수 후 1개월: TeslaMate 별도 설치 여부 결정
4. 설치 후: 우리 앱에서 쉬운 요약 화면 제공
