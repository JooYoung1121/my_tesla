## 2. 서비스별 상세 (사실 / 추정 구분)

### TKC (Tesla Korea Club)
- **[사실]** 사이트 고지문: "가격·보조금·입항·인도 예상은 공개 자료와 TKC 등록 기준으로 정리한 참고 정보"이며 "테슬라 공식 판매처나 대행사가 아니다". 출처: https://tkc.kr/
- **[사실]** 입항 페이지는 도착/도착예정 선박 기준으로 **확인된 대수와 '확인 중 후보'를 분리** 표시하고, 하역 후 통관·PDI·배정·결제·등록에 며칠~몇 주가 더 걸린다고 안내. 출처: https://tkc.kr/ship (검색 요약)
- **[추정, 신뢰도 중]** 회원들이 카페 댓글로 공유한 닉네임·외장/내장색·결제일·보조금 신청 여부·인도예약일을 **운영자가 매일 수동 정리**하는 커뮤니티 방식. 관세청 등 공식 API 연계는 확인되지 않음. 근거: 검색 요약(https://tkc.kr/ship, https://namu.wiki/w/테슬라코리아클럽)

### 지지직 (ZIZIZIK) — 전기차 미션 플랫폼 앱의 웹 콘텐츠
- **[사실]** "테슬라 적재 확률은 과거 운항 이력을 기반으로 추정한 것" 고지문 존재 → **AIS/운항 이력성 데이터로 특정 자동차운반선의 테슬라 적재 여부를 확률로 추정**. 출처: https://zizizik.app/contents/kr/vessel-arrival
- **[사실]** UI = 선박 카드(선박명·출발/도착지·상태 단계) + 모델별 탭 + 날짜별(연월) 모델별 대수 집계표 + 업데이트 타임스탬프.
- **[추정, 신뢰도 중]** 회원 제보(차량·통관 정보)를 보조 신호로 결합해 대수를 보강.

### EvTmate — 개인 개발 비공식 앱 (App Store)
- **[사실]** "개인이 개발한 앱, 공식 아님" 명시. 4대 기능: 입항 정보 / 전기차 보조금 / 계약 후 날짜 계산 / VIN 연동 텔레메트리. 출처: https://apps.apple.com/kr/app/evtmate/id6751030275
- **[사실]** **Tesla Owner API 연동**으로 인앱 로그인·계약인증 뱃지·VIN 발급현황(계약→발급 소요일, VIN 실제모델 판별)·배터리 사용량 제공 — 3곳 중 유일하게 개인 계정 데이터를 직접 끌어오는 차별점.
- **[사실]** 입항은 선박명·총 대수·모델별 합계, 인도 이력은 색상·모델·구동계·지역 필터, 보조금은 전국 102곳 잔여 현황 지도.
- **[추정]** 입항 데이터 원천은 명시 안 됨 — PORT-MIS/AIS 계열로 추정. VIN·인도 데이터는 사용자 계정 집계.

### 공통 공개 데이터 확인
- **[사실]** PORT-MIS 선박입항신고/선박관제정보는 공공데이터포털에 오픈API(REST, JSON/XML)로 제공, 회원가입·활용신청 필요. 선박 호출부호·신고항만명·입출항일시·계선장소·전출항지 포함. 출처: https://www.data.go.kr/data/15128161/fileData.do , https://www.data.go.kr/data/15128156/fileData.do
- **[사실]** 관세청 유니패스 수입실적을 통한 모델별 대수 직접 연계는 어느 서비스에서도 확인되지 않음(개별 VIN 통관 정보는 개인정보라 비공개).

## 3. 우리 사이트(PORT-MIS 기반 평택항 추적 구현됨) 추가 도입 아이디어

| # | 기능 | 실현 가능성 | 벤치마크 |
|---|---|---|---|
| 1 | **AIS 실시간 선박 위치·ETA** (지도/D-day) | 실현 가능(MarineTraffic·VesselFinder 유료 API, 또는 무료 aisstream.io) | 지지직 '선박 카드' |
| 2 | **입항→인도 소요일 코호트 통계** (분포·중앙값 히스토그램) | 실현 가능, 자체 데이터로 재현 | TKC "통관~등록 며칠~몇 주" 안내를 데이터화 |
| 3 | **자동차운반선(PCTC) 필터링** (글로비스·유코카캐리어스 등) | 실현 가능, 무료(PORT-MIS 선박종류·선사 코드) | 지지직 '적재 확률'의 단순·재현가능 버전 |
| 4 | **Tesla Owner API 개인 VIN 트래커** | 실현 가능하나 리스크(비공식 API 정책·인증 변경, 개인정보 보관 부담) | EvTmate |
| 5 | **선박별 모델 대수 추정** | 불가능에 가까움(공개 API 없음) — 하려면 커뮤니티 제보 입력 폼 필요 | 지지직·TKC(제보·확률 의존) |
| 6 | **입항 알림(웹푸시/푸시)** | 실현 가능(PORT-MIS 폴링→대상 선박 입항 시 알림) | EvTmate 사용자 요청했으나 미구현 → 선점 가능 |

**판단 요약**: 공개 API로 재현 가능한 것은 (1) AIS 위치·ETA, (2)(3) PORT-MIS 정제·필터링·소요일 통계, (6) 알림. 모델별 대수(5)는 제보 없이는 불가. VIN 연동(4)은 가능하나 비공식 API 리스크 감안 필요. 가장 낮은 비용으로 차별화할 수 있는 건 (6) 입항 알림과 (3) 자동차운반선 필터링임.
