# 테슬라 기초 지식

최종 업데이트: 2026-06-11

## 결론

모델 Y가 중국 공장에서 만들어졌다는 말은 한국 RWD 모델 Y 맥락에서 대체로 맞는 이야기다. 다만 FSD 가능 여부는 공장 하나로 결정되지 않는다. 실제로 중요한 것은 판매 지역, 차량 구성, 구매 옵션, 어시스티드 드라이빙 하드웨어, 소프트웨어 버전, Tesla 계정의 업그레이드 가능 여부다.

## 중국 생산 여부

2023년 7월 테슬라 차이나가 상하이 기가팩토리에서 생산한 RWD 기반 모델 Y를 한국에 수출하기 시작했다는 보도가 있다. 그래서 한국에서 판매되는 RWD 계열 모델 Y를 이야기할 때 “중국산 모델 Y”라는 표현이 자주 나온다.

단, 내 차량은 주문 상세, VIN, 등록 서류로 최종 확인한다. 같은 모델 Y라도 판매 시점, 트림, 지역, 재고 상황에 따라 생산지가 달라질 수 있기 때문이다.

확인할 것:

- 주문 상세의 원산지 표기
- 차량 등록 서류
- VIN 디코딩 정보
- Tesla 앱 또는 차량 화면의 차량 정보

## FSD가 안 된다는 말의 의미

“중국산이라 FSD가 안 된다”라고 단정하면 부정확하다. Tesla 매뉴얼은 풀 셀프 드라이빙(감독형)이 판매 지역, 차량 구성, 구입 옵션, 어시스티드 드라이빙 하드웨어 및 소프트웨어 버전에 따라 장착되어 있지 않을 수 있다고 설명한다.

즉 판단 기준은 다음 순서로 보는 편이 맞다.

1. 한국에서 해당 기능이 현재 제공되는지
2. 내 차량이 FSD 지원 하드웨어인지
3. 주문 시 FSD 옵션을 샀는지
4. 출고 후 Tesla 앱 또는 차량 화면의 업그레이드 메뉴에 FSD가 표시되는지
5. OTA 업데이트 후 기능이 활성화되는지

## 소프트웨어 업그레이드로 FSD를 켤 수 있나

가능한 차량이라면 출고 후에도 Tesla 앱 또는 차량 터치스크린의 업그레이드 메뉴에서 FSD 관련 옵션을 볼 수 있다. Tesla 지원 문서는 기존 소유 차량도 Tesla 앱이나 차량 터치스크린에서 FSD(감독형)를 구독할 수 있고, 기능 사용 전 소프트웨어 업데이트가 필요할 수 있다고 설명한다.

다만 월 구독 제공 국가는 수시로 바뀌며, Tesla 지원 문서의 국가 목록에 한국이 항상 포함된다고 단정하면 안 된다. 한국에서는 앱에 표시되는 실제 구매/구독 가능 여부와 Tesla 계정 기준 안내를 우선 확인한다.

## 오토파일럿과 FSD 구분

- 기본 안전 기능: 자동 긴급 제동, 충돌 경고 같은 안전 보조 기능
- 오토파일럿: 교통 인식 크루즈 컨트롤과 오토스티어 중심의 주행 보조
- 향상된 오토파일럿: 일부 시장에서 자동 차선 변경, 자동 주차 등 확장 기능
- FSD(감독형): 목적지 주행, 교차로 판단, 회전, 고속도로 진출입 등을 시도하는 고급 운전자 보조

FSD(감독형)는 이름과 달리 완전 자율주행이 아니다. Tesla 한국 Model Y 페이지도 FSD(감독형)는 운전자의 적극적인 감독이 필요하며 차량을 완전 자율주행 상태로 만들지 않는다고 안내한다.

## 인수 후 확인 체크리스트

- Tesla 앱 > 업그레이드 > 소프트웨어 업그레이드 확인
- 차량 터치스크린 > 컨트롤 > 업그레이드 확인
- 차량 터치스크린 > 컨트롤 > 소프트웨어에서 차량 정보와 컴퓨터 확인
- 카메라 보정 상태 확인
- 지도 업데이트와 차량 소프트웨어 업데이트 확인
- FSD 후기 글을 볼 때 차량 연식, 하드웨어 세대, 생산지, 배포 국가를 같이 기록
